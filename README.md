# workshop-npk

Personal side projects written in [Nitpick](https://github.com/alternative-intelligence-cp/nitpick): ports of open-source programs and other experiments, one folder per project.

**What this repo is, and isn't.** These projects are built carefully and tested, but they haven't been through the Alternative Intelligence Liberation Platform's full audit and vetting process. That process is only for what lives in the [AILP organisation](https://github.com/alternative-intelligence-cp) (the compiler, the standard libraries, the docs). Treat the code here as you would any individual's project: read it and test it before you rely on it.

## How the work is done

Most of the code is written by AI models, working in teams with a manager model, and each project credits its models by name and role. See [`WORKFLOW.md`](WORKFLOW.md) for how changes reach `main`.

Each port keeps its original project's licence and credits its original authors in its own folder.
